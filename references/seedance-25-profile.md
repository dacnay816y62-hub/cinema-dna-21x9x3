# Seedance 2.5：入口适配与提示词边界

重点用完整自然语言表达参考职责、动作状态、相机路径、剪辑和声音；不将作者的内部标签或时间码当作平台强制控制字段。

## 选择实际入口

单图起始、可选尾帧、多参考、逐镜独立、多镜同段与已有视频延长是不同任务。只上传身份/风格参考时，不把它冒充首帧；没有源视频不能宣称已绑定延长。网页、API、Draft 与最终渲染的能力和计费可能不同。

编写正文不需要密钥，也不自动提交。实际生成前刷新所选入口的官方说明和账户界面，核对：
- 模型/版本与任务模式；
- 真实附件标签、参考数量、首尾帧支持与各参考职责；
- 时长、画幅、分辨率、音频、输出格式和费用；
- 是否确有负面字段、种子或专门运动控制；查不到的功能写未验证。

## 字节官方写作依据

2026-11-19 核对 [官方提示词指南](https://docs.volcengine.com/docs/ark/seedance-2-5-prompt-guide?lang=zh) 与 [模型教程](https://docs.volcengine.com/docs/ark/seedance-2-5?lang=en)。重点采用以下边界，不把平台教程当作模型官方规范：

- 九宫格可表达分镜语义，但不等于逐格精准锁帧；需要明确画面控制时准备独立关键帧，按当前入口绑定。
- 事件按连续时段或镜序安排，描述长度与实际动作量相称；细化关键交互，不给所有动作规定频次。
- 引用材料说明实际职责。已有准确动作或运镜参考时，避免另一套文字路径与之冲突；陌生摄影术语换成可见的机位变化。
- 首尾帧、编辑、延长与参考生成是不同任务；时长、比例等约束随任务变化，不能用一段通用参数套所有入口。

正文采用中文。具体上传标签属于平台绑定操作；本技能的九栏是交付格式，不是官方语法。官方页面链接的飞书模板需登录，本次未读取，不纳入已读证据。

## 平台 API 文档快照

2026-11-19 查阅 Higgsfield 的两个公开端点：
- [单图图生视频](https://open.higgsfield.ai/models/bytedance/seedance-2.5/image-to-video/api-reference)：起始图、可选尾图、时长、分辨率、格式与音频。
- [多参考视频](https://open.higgsfield.ai/models/bytedance/seedance-2.5/reference-to-video/api-reference)：图片/视频/音频引用及画幅等设置。

这些仅帮助找到入口，不是永久能力保证；执行时以最新参数表为准，不把一个端点的字段移植到另一个。正文写“8K”不等于文件是8K，写“无声”也不能替代已支持入口的音频设置。不要把网页宣传能力泛化成所有 API 均支持。

## 写法与限制

参考可以按身份、画风、空间和动作阶段分工，但数量不应多于必要；不要复制别人的元素 UUID 或未验证的 `@图片1` 绑定。用实际上传顺序或文件名说明对应关系。

时间段与摄影术语表达导演意图，不保证逐帧切点、完整360度、精确口型或物理交互。复杂任务按故事事件合理拆段，不能靠堆叠术语提高承诺。

[Higgsfield 平台提示词指南](https://higgsfield.ai/blog/seedance-2-5-prompting-guide) 可用于比较组织方式，但不是字节官方文档；其长案例、旧规格及推广结论不等于本技能已验证的性能。规则来源与抽样边界见 [研究记录](research-notes.md)。不复用社区人物、完整提示词或未获许可的媒体包。
