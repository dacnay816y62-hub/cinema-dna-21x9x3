# 图像事实 → 导演设计 → 平台提示词

## 1. 只建立有用的事实

简单单镜可在内部完成以下判断，不输出冗长表格。多人/九镜需落到账本。

| 层 | 记录 | 不能混入 |
|---|---|---|
| 原故事 | 必须发生的事实、指定顺序与结局、允许补充 | 擅加反转、死亡、浪漫关系 |
| 参考职责 | 原文件名、实际上传序号、身份/服装/产品/空间/画风/起态/尾态 | 把风格参考的构图强制当首帧 |
| 已知空间 | 可见相邻、遮挡、地面接触、开口、通道、光源 | 单图没显示的反面和房间尺度 |
| 实体状态 | 每个角色与关键物件的数量、归属、位置、阶段 | 把携带物永远算作身份特征 |
| 当前镜头 | 新信息、起态、事件、尾态、机位、剪辑关系 | 只有“高级、震撼、电影感” |

来源事实使用 F1/F2，角色和重要物件使用 A/B/P1 等内部 ID，正文用自然名称。来源图若互相矛盾，先按用户明确优先级处理；影响主体身份或空间真相时不能自作主张混合。未知光源可以合理推测，但标为设计假设，不称图中事实。

一张完整参考可以同时负责身份和空间，但只包含其可见证据。空间图中的人物不一定负责身份；人物图背景不一定进入新场景；三视图不是三个人。

## 2. 从“这一帧”向前还是向后

- **首帧**：动作只能从画中状态出发。手已松开，不再写“第一次放下”。
- **中间帧**：用于动作阶段/造型参考；若需要前半动作，单独设计开场，不谎称该图就是开场。
- **尾帧**：从合理初态抵达尾态；首尾空间差异过大时提出切镜/补图/分段方案。
- **风格或身份参考**：不锁站姿、道具归属、机位，除非用户同时指定。
- **已生成视频**：查看实际尾段，不只读取脚本。动作停在接触前、承重中还是释放后，决定如何接续。

“延续故事”允许硬切到下一观察角度；“延长视频”是平台延长入口与尾段连续性约束；“首尾帧过渡”是两个端点；“镜间动作匹配”是后期剪辑关系。四者分开记录。

## 3. 导演卡：只留会影响画面的内容

```text
镜号 / 故事事实 / 观众在本镜新增知道什么
输入帧角色 / 实际参考绑定 / 继承状态
起始：主体位置、朝向、动作阶段、道具归属
动作：触发 → 关键变化 → 可见结果
摄影机：观察位置 → 主运动及路径 → 速度/停顿 → 终点构图
焦点：谁清楚、何时转移、转移的叙事原因
空间：轴侧、可走通道、遮挡、前后层次、尺度依据
尾态：主体/物件在哪里、谁已松手、还剩哪一段动作
剪辑：硬切 / 动作接续 / 声音先行 / 无切镜 / 明确跳时
光影与媒介：光源位置、材质/受光变化、需保留的画风
声音：现场声、动作声、台词说话人、配乐或静默
```

动作持续时间是导演计划，不是假装已测得。小表情不必逐帧规定；关键交接、转身、开门和走位给足准备、动作、落定的时间。台词先按语言正常读一遍估时，不能靠缩写时间码把一大段塞进两秒。

## 4. 运镜词必须对应一个物理行为

| 意图 | 正确描述 | 观察证据/常见混淆 |
|---|---|---|
| 推近 | 摄影机沿可通行方向靠近，最后停在哪个景别/关系 | 前景与后景比例有视差；不是只放大裁切 |
| 横移 | 摄影机向指定场景锚点横向平移，说明跟随还是掠过 | 柱边、人物、远背景不同速率掠过 |
| 摇摄 | 摄影机原地转动拍向，明确起点和停止对象 | 机位没搬家；不是环绕主体 |
| 跟拍 | 主体怎样走，摄影机保持什么距离/侧向关系，如何避障 | 主体真的经过固定地标，不是原地踏步 |
| 小弧绕 | 以哪个主体为中心、从哪侧到哪侧、揭示什么 | 必须有该侧空间；单图不默认绕到未知背面 |
| 升降 | 摄影机升/降后揭示何物，俯仰是否另行改变 | 不是人物忽然缩放或楼层漂移 |
| 移焦 | 摄影机位置是否固定，清晰对象从谁到谁，何时 | 移焦不等于推拉，不凭空改变空间 |
| 手持 | 由站立呼吸、行走或追赶产生何种小幅修正 | 不默认剧烈抖动；摄影机重量不等于加乱震 |

复合运镜应有先后或清楚的主从关系，例如“横向跟随，到门口后停住，再轻摇至留在屋内的人”。若同时高速绕人、升高、推近、变焦，先判断是否有叙事必要和空间依据；不能只是词库堆叠。

距离、焦距、角度优先使用已知值；无测量依据时用“肩高、隔桌、沿可见走道、停在手与物件同框”等关系描述。不得编造厘米数制造精确感。设备/胶片品牌只是可选成像意图，不是已验证的拍摄参数。

## 5. 空间与轴线

建立角色动作线/视线轴及摄影机所在一侧。固定同侧拍摄时保持进出和视线可接；不要把“人物永远屏幕左边”当成世界位置。

需要跨轴时，应设计中性轴线镜、看得见的连续移动或重新建立地理的镜头；记录跨轴理由与重新定向。背拍转正拍可能左右换屏，但人物没有互换座位。轴线正确不代表透视正确，还要核对脚点、地面、遮挡、接触距离和参照物尺度。

多人场面给每个重要角色关系和活动，不必全员同时运动。群像齐步、齐笑、齐转头通常应避免，除非剧情明确要求。两个人被同一前景遮住，不代表人数减少。反射与屏中人也不自动算新角色。

## 6. 九镜连续性不是九次重置

为关键物件保存：数量、持有人/所处位置、开合、是否已释放。交接链通常是 A 独持 → 双方接触同一件物品 → B 独持且 A 空手。

每镜写前态/变化/后态；下一镜从前镜后态开始。取回、修复、跳时和闪回均可改变状态，但必须有事件。关键身份图若携带已交走物件，只参考身份，不继续参考物件。

九镜至少核对两层：相邻动作接续，以及远距离因果（第三镜留下钥匙，第九镜不能无故在手里）。覆盖原故事而非凑九个事件；允许反应镜和空镜，不强迫悬疑反转。

独立生成每镜时用已验收的角色/风格锚点和当前状态参考，不能只链式引用上一张导致风格漂移。参考已经失败时停止向下传播，修关键镜并复查依赖镜。

## 7. 媒介、光影和声音也有连续性

二维画风要锁定轮廓、色块、纹理落点与运动节奏；是否逐帧、停格、流畅运动取决于用户和原图，不把所有手绘都规定为同一种帧节奏。指定可辨角色必须真正出现，不能拿烟雾轮廓加角色名冒充。

光源留在场景里，不跟着镜头无因翻面。写清物理变化：人经过窗边时宽柔受光区域扫过肩部；横移使木纹高光相对滑动；雨滴落水形成涟漪。没有日照依据不添加太阳或树影，夜景不自动改黄昏。

声音注明谁说什么、何时进入和停止；反打时上一句可以跨切延续，但不要把切点落在必须完整听见的词中。环境声可以连贯，多场景切换需合理变化。未听视频音轨，不报告其音效/配乐是否达标。

## 8. 编译成正文，而非把账本原样粘贴

信息优先级：用户最新要求 → 实际资产事实/参考边界 → 故事与当前状态 → 镜头和声音 → 可选质感修饰。删去重复、冲突、无关设备词及未绑定标签；不用删关键事实换取机械字数达标。

短单镜可在固定模板每栏各写一句。复杂多镜用中文编号和时间段，显式硬切/连续拍摄。默认九栏见[中文固定模板规范](中文固定模板规范.md)；用户明确指定其他格式时优先，模板不是模型必需的接口语法。

交付正文之外附最少说明：上传清单、建议设置、缺口与未验证项。每次返修给完整新版，保留未受影响的创意，别让用户手动拼接。
