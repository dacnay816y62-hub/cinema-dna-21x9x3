# 完整中文视频提示词：固定交付规范

用于视频提示词、分镜配运镜及提示词工作台。默认读取并填写 [完整视频提示词模板](../assets/提示词模板/完整视频提示词模板.txt)，而非临时设计栏目。用户明确只要静帧时不强制增加视频任务；明确指定其他输出格式时尊重该格式，完整性要求仍保留。

## 必须交付什么

每个独立提交片段都给一份完整正文，固定九栏顺序：片段任务 → 素材绑定 → 场景与起始状态 → 分镜时间轴 → 摄影机与焦点 → 表演与物理反馈 → 光线与画风 → 声音与台词 → 结束状态与限制。

- 标题、正文、运镜词、对白和使用解释全部中文，不附英文版，不以英文术语显得专业。品牌原版标志、链接、代码字段与原始文件名不擅自翻译改名；这些放在正文之外。正文用“图片一（人物）”“视频一（运镜）”等中文称呼，在上传清单对应真实文件与实际平台标签。
- 默认交付的是填完的提示词，不是空白表格、栏目说明、导演卡或清单文件。仅当用户明确索要空白模板时，才原样提供填空版。
- 每栏使用自然可读的完整句子，短单镜可每栏一句，不设最低字数。只展开有叙事作用的动作，避免九栏互相复述。
- 一段一个连续正文块、一份文本文件；网页复制区域与文本文件完全相同。共同风格和状态在各独立片段重复写全，不能让用户拼接“公共前缀＋镜头正文”。
- 镜头数量、段数、秒数由故事、实际入口和用户限制决定；九栏不等于九镜，不默认三段，不默认三十秒。每段时间轴从零开始，时段相接且覆盖计划时长。
- 无参考素材时明确文生方案，不写假附件。参考只有单张正面空间图时，不要求毫无依据的背面环绕。未知但不影响写作的细节使用保守设计，并在正文外注明设计假设；关键缺口仍需确认。

## 来源如何转成规则

这是本技能自行整理的交付格式，不是模型官方要求的九段语法。

| 来源 | 借鉴的方法 | 在模板中的位置 |
|---|---|---|
| [字节官方提示词指南](https://docs.volcengine.com/docs/ark/seedance-2-5-prompt-guide?lang=zh) | 材料职责明确、事件按顺序表达；优先可见的正向动作 | 素材绑定、分镜时间轴 |
| [字节官方模型教程](https://docs.volcengine.com/docs/ark/seedance-2-5?lang=en) | 按真实任务类型核对入口，语言支持不要求把中文转为英文 | 片段任务及正文外的提交说明 |
| [社区《十四天》](https://higgsfield.ai/@cheney/projects/14-days) | 分开约束画风、空间、身份与姿态，沿用当前状态 | 素材绑定、场景与起始状态、结束状态 |
| [平台提示词指南](https://higgsfield.ai/blog/seedance-2-5-prompting-guide) | 分离相机、材质运动、照明及声音，便于核对各自责任 | 摄影机、物理反馈、光线、声音 |
| [用户提供的《长安异闻录》第三卷项目](https://www.liblib.tv/creation/process?id=386cfd274d084d2ba9add9dc8480427e) | 视频模板与人物、场景资产各司其职；目的推动行动、对白对应说话人和时机 | 片段任务、场景起始、表演、声音、结束状态 |

社区文本不是成功保证：本次查看的片段仍需逐项核对，不复制其故事、英文混写、内部字段或冗长禁令。详细证据与日期见 [研究记录](research-notes.md)。网页/API/模型版本能力不可互相移植，见 [入口适配](seedance-25-profile.md)。

十四模块案例不机械变成十四项强制填写：把人物目的和可见情绪纳入表演，把对白归属纳入声音，把继承情绪纳入结束状态。多角色、有台词或发生走位时才展开对应细节；无冲突的观察镜头不凭空增加障碍。人物定妆图不继承棚拍背景，空间母版不强制复制其中的临时人物。资产中出现的时代判断仅属该项目设定，不作为本技能核实过的历史事实。

## 固定流程与完成门槛

1. 读取真实剧情、参考和当前状态，按事件决定片段覆盖镜号。
2. 按九栏填写每段，删掉全部填空说明；检查镜头动作和相机路径不矛盾。
3. 核对实际附件顺序、首尾职责、时长与剪辑模式；将说明写在正文之外。尚未上传时称“上传计划”，不能称“已绑定”。
4. 有文件任务时写入完整中文文本，运行 `scripts/check_prompt_template.py`，再由原工作台生成器建页。生成器默认执行相同结构检查；缺栏、空栏、残留填空或英文字母会报错。
5. 人工检查原故事覆盖、动作可达性、参考映射、连续状态、时间安排和声画关系。结构检查不能判断这些事实，更不能证明视频成功。
6. 最终答复提供正文或能直接打开的完整文件链接，注明视频是否实际生成。不能只说“已经整理好模板”而没有交付正文。

脚本环境不可用时仍在聊天交付填好的九栏正文，不以无法生成网页为由省略提示词。用户明确要求自定格式或整理旧稿时，可在清单填写 `prompt_format: "自由格式"`；不得为掩盖缺栏或英文残留而静默切换。该选项只改变结构校验，不表示内容验收通过。
