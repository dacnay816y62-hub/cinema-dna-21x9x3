# 九镜拼版使用说明

3.2.3 修复 [问题 #2](https://github.com/dacnay816y62-hub/cinema-dna-21x9x3/issues/2)。macOS（含 Apple Silicon）和 Linux 改用 Python + Pillow，不再调用只支持 Windows 的 `System.Drawing`。Windows 原 PowerShell 路径继续可用，不强制新增依赖；也可以选择 Python 入口。

## macOS / Linux：推荐直接使用 Python

需要 Python 3.9 或以上。在仓库根目录执行以下命令；虚拟环境只用于拼版，不修改系统 Python：

```bash
python3 -m venv .venv-storyboard
.venv-storyboard/bin/python -m pip install -r scripts/requirements-storyboard.txt
.venv-storyboard/bin/python scripts/compose_nine_shot_storyboard.py \
  --sources shot01.png shot02.png shot03.png shot04.png shot05.png shot06.png shot07.png shot08.png shot09.png \
  --output-dir "交付/九镜拼版" --prefix demo
```

把九个文件名替换为实际源图，按镜号顺序逐一列出。中文、空格路径用引号包住；不要依赖通配符排序。如果 Linux 提示没有 `venv`，先通过该发行版包管理器安装对应 Python 的虚拟环境组件。

## 继续使用 PowerShell

macOS / Linux 已安装 PowerShell 7 时，在 bash / zsh 中也可运行原脚本。新版本同时接受下面九个独立路径的写法：

```bash
pwsh -NoProfile -File scripts/compose-nine-shot-storyboard.ps1 \
  -Sources shot01.png shot02.png shot03.png shot04.png shot05.png shot06.png shot07.png shot08.png shot09.png \
  -OutputDir "交付/九镜拼版" -Prefix demo \
  -PythonExecutable .venv-storyboard/bin/python
```

不指定 `-PythonExecutable` 时，macOS / Linux 按当前命令路径依次寻找 `python3`、`python`。Pillow 必须安装在实际使用的解释器中；推荐像上例显式指定虚拟环境。脚本不会自动安装软件、修改系统设置或下载源图。Python 失败会返回错误，不会把失败当成完成。

Windows PowerShell 中保留原调用方式，无需 Python：

```powershell
$sources = @('shot01.png','shot02.png','shot03.png','shot04.png','shot05.png','shot06.png','shot07.png','shot08.png','shot09.png')
./scripts/compose-nine-shot-storyboard.ps1 -Sources $sources -OutputDir '交付/九镜拼版' -Prefix demo
```

Windows 也可安装 `scripts/requirements-storyboard.txt` 后直接运行 Python 脚本，或通过 `-PythonExecutable` 指定解释器使用同一跨平台后端。

## 输出与参数

| 内容 | 文件与默认尺寸 |
| --- | --- |
| 9 张独立镜头 | `demo_shot01.png` 至 `demo_shot09.png` |
| 3 张纵向三联 | `demo_triptych_1.png` 至 `demo_triptych_3.png`，每张 1920 × 2425 |
| 1 张九宫格接触表 | `demo_3x3_contact_sheet.png`，2896 × 1222 |

- 默认接触表单格 960 × 402，黑色间隔 8 像素；按输入顺序从左到右、从上到下排列。
- Python 参数：`--cell-width`、`--cell-height`、`--gap`；PowerShell 参数：`-CellWidth`、`-CellHeight`、`-Gap`。宽度范围 320–3840，高度 134–1607，间隔 0–64。
- 沿用旧版尺寸规则：三联的宽度为单格宽度的两倍，每格高度按宽度 ÷ 2.39 四舍五入；`cell-height` 只控制九宫格，不控制三联。修改尺寸时先核对目标比例。
- 不裁切、不拉伸、不加文字，等比缩放后居中，空白和透明处以黑色呈现。不同后端的抗锯齿可能略有差异，不承诺逐像素相同。
- Python 后端的独立 PNG 源图按原文件复制；其他支持的静态图片转换为真正的 PNG。拼版会应用照片的方向信息，原始源文件不被改写。不要把动画或视频当作静帧输入。
- 重跑会替换相同目录、相同前缀的交付文件；需要保留旧版时换前缀或目录。Python 后端拒绝输出覆盖任何输入源图，并在完整解码九张图片后才生成交付。
- Python 返回 JSON，PowerShell 返回对象，均包含源图数、单图数、三联数、接触表路径及宽高，便于后续工作台使用。
