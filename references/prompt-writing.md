# 3.2 的重点：把导演意图写成能看见的变化

先消化图像和剧情，再写正文。内部账本用于校对，用户拿到的是一条独立完整、自然可读的中文提示词，不是标签列表。以下是针对本技能的写作方法，不是 Seedance 官方固定语法，也未经生成实验证明优于所有写法。

正文默认按[中文固定模板规范](中文固定模板规范.md)填满九栏。每个栏目写完整句子，方法用于填入内容，不能代替实际提示词；不再自由选择栏目或回退为英文短句。素材准确时简洁指代，不用重复复述图片；关键接触动作才展开顺序，次要动作概括即可。

## 1. 先写一句镜头的“动词主干”

用“谁想做什么 → 发生什么可见变化 → 停在什么结果”组织。人物的心理通过目光、停顿、距离、动作完成与否显现，不只写“她很悲伤”。

例如：她提灯走近长凳，把灯放在老人旁的空位，松开提手后没有坐下。

这句决定动作。摄影机负责让人看清这一变化；不要先写宏大环绕，再硬塞故事。

## 2. 参考图职责：写继承什么，也写不继承什么

四种职责不是必须四张图；同一图可兼任，但权限不能冲突。

| 职责 | 正文应说清 | 常见误写 |
|---|---|---|
| 画风 | 保留媒介、线条、色块、纹理与细节密度；是否继承色调另定 | “参考图片1”却把人物和灯光全带过去 |
| 空间/产品 | 固定可见结构、相邻关系、材质与真实比例；是否固定机位另定 | “保持一模一样”同时要求无依据的背面 |
| 角色 | 锁面貌、年龄、发型、服装中被指定的部分 | 旧图手里有伞，后续永远多出一把伞 |
| 动作状态 | 这张是开场、过程还是落点，手与物件当前关系 | 只作结尾参考，却把它设成首帧 |

自然句式：上传的场景图固定长凳、立柱和水岸关系；摄影机始终在岸侧可见地面活动，不继承另一张人物定妆图的背景。不能留下未填写的模板或未实际上传的标签。

## 3. 一次写清动作与表演，别把它们挤到禁令里

正向描述优先：灯底接触木面，她停一下，手指展开离开提手，灯留在原处。末尾只补必要限制，例如全段只有这一盏手提灯。

“不穿模、不瞬移、不变形”不能替代接触顺序。交接给出受力与释放；坐下给出靠近、弯膝和落座；走路给出经过哪个固定地标。姿态变化与主体真实位移分开写。

副动作少而有因：衣摆因停止行走而回落，水面因雨滴出现涟漪。不要让每个人同时做眨眼、微笑、歪头、抬手一整套动作。

## 4. 摄影机用一条完整路径句

起始观察点 + 主运动 + 跟谁/揭示什么 + 停止条件。

- 推近：摄影机从岸侧双人全景沿空地缓慢靠近，柱与远岸产生不同程度的视差，最后停在手、提手和凳面同框的中近景。
- 摇摄：机位留在岸侧原地，只转动拍向，从提灯的女人摇到仍坐着的老人；不移动到长凳背后。
- 移焦：摄影机保持位置，先看清松开的手，随后把焦点交给老人抬起的眼睛；不伴随变焦。

这些句子只在所见空间确实容纳时使用。不要把一个镜头同时写成固定机位、横移、环绕和变焦；需要组合就安排先后。焦段、设备和角度是可选补充，不替代路径。

## 5. 多镜用“动作切点”，不只列画面目录

上一镜切出时是什么进度，下一镜接哪一部分？

弱：镜头1走路，镜头2放灯，镜头3老人特写。

更明确：第一镜在她靠近凳前、手仍握提手时切出；第二镜从这个持灯状态开始，完成接触和松手；第三镜灯已在凳上，老人这时才把视线移向灯，女人的手不会再次出现在提手上。

一镜到底不使用硬切、瞬间反打或从外景突然进入无法通过的室内。多镜剪辑不要求摄影机穿过所有机位。原故事没有的反转，不为了镜头变化而添加。

## 6. 质感写成具体视觉关系

先保留原图，再指定本镜最重要的材质和受光。例如雨后石面有零碎反光，灯的暖光只影响附近手和衣角，远岸仍为冷灰；不让整幅图因为提灯变暖。

手绘片写笔触如何维持和动作如何表现，不默认毛孔、镜头眩光与写实3D。需要压迫感时写遮挡、距离和观看位置；需要空灵时写留白与层次，不用滤镜词代替构图。

## 7. 声音是有对象的时间线

区分环境、动作、对白、配乐；各自说明由谁产生、何时出现。灯接触木面时才有轻碰声，尚未落下时不先响。台词跟着说话人和镜头时间；保留用户指定台词，不随手加旁白解释剧情。

无音乐不是所有题材默认值。未指定声音且场景适合自然现场声，可说明采用该方案；若精确音乐/口型是核心而音源缺失，先确认。

## 8. 保留重要约束，删重复与相互抵消

将要求分成三层：

1. **必达**：角色、故事动作、关键道具、画风、空间、结束状态。
2. **镜头表达**：景别、运镜、焦点、节奏、光影。
3. **可选修饰**：设备名、细小装饰、非必要表情与环境活动。

发生冲突先按用户意图解决；任务复杂度过大时说明选择，不悄悄删除核心动作。不是简单删成短提示词，也不是所有细节都标“最高优先级”。优先级按维度分配：场景图管几何，脸图管身份，不用一个笼统全局排名覆盖全部。

输出前读一遍正文：先看到什么、谁先动、摄影机为何动、如何切、最后留下些什么。用户应能读成一段可以拍摄的指令。

## 9. 对照案例时要追问的五件事

1. 原提示词具体承诺了什么？引用其意图而非长篇复制原文。
2. 同一生成ID的画面是否真的体现？不能拿成片混剪冒充某条原始生成。
3. 哪些看到了，哪些抽帧不足以判断？声音未听就不评价。
4. 成功可能来自参考素材、后处理或模型设置，不能全部归功于文字。
5. 迁移的是怎样写职责/动作/机位，而不是照搬剧情、人物、参考UUID和所有禁令。

失败后输出“观察 → 可能原因 → 完整新提示词”。比如受限视窗变得过宽，先核对是否引用了不受遮挡的画面，再明确前景遮挡边界和终点构图；不能仅在末尾追加“不要变宽”就称已修复。
