# 文件与提示词交付｜3.2

用户只在聊天里要正文时直接给正文，不强制文件包。需要文件时遵守用户目录与格式；中文项目使用中文任务文件夹，完整提示词用 UTF-8 TXT，不以 MD 代替。

## 图文工作台

图像加提示词的文件交付默认包含可本地打开的 HTML，单看 TXT 或只要原图时不额外追加。工作台把分镜、参考职责、段号/覆盖镜号、计划时长、片段模式与完整提示词放在一起，提供复制与 TXT 下载；有真实视频才提供播放器。

生成片段数由剧情决定，不硬绑图数。建议结构：

    故事名称/
      分镜与提示词.html
      交付清单.json
      九镜总览.png                 # 仅在请求九镜且实际已生成时
      分镜图/                     # 保留独立图与原始镜号
      段落01_事件名称/
        视频提示词.txt
      段落02_事件名称/
        视频提示词.txt

用户要导演卡、真实提交记录或全部提示词汇总时再附，不无条件铺满过程文件。图片是首帧、中间状态、尾帧还是身份/画风参考必须可读；同一参考被多段使用不等于新增镜头。

## 轻量生成器

附带 [build_prompt_html.py](../scripts/build_prompt_html.py)，Python 3.9+ 标准库即可运行，不需要 API 密钥、网络、额外依赖或生成额度。脚本只读取已准备的素材和 TXT，生成 HTML；不编写提示词、不生成图片或视频。

在任务目录准备 `交付清单.json`，所有文件路径相对该清单且位于该目录内：

```json
{
  "title": "山寺借伞",
  "segments": [
    {
      "id": "P01",
      "title": "檐下交接",
      "shot_ids": ["04", "05"],
      "mode": "多镜剪辑",
      "duration": "计划8秒",
      "prompt_file": "段落01_檐下交接/视频提示词.txt",
      "images": [
        {"path": "分镜图/镜头04.png", "role": "起始状态：两人共同接触同一伞柄"},
        {"path": "分镜图/镜头05.png", "role": "尾态：接收者独持，原持有人空手"}
      ],
      "status": "提示词已检查，视频未生成"
    }
  ]
}
```

`images` 可为空；不虚构缺失图片。`video` 只填包内已有的真实视频相对路径。状态按实际检查记录填写，脚本不自动验收。以上为字段说明，不是可直接提交的镜头正文。

```text
python scripts/build_prompt_html.py 路径/交付清单.json
```

默认在清单同目录生成 `分镜与提示词.html`。已有文件不覆盖，明确需要更新时加 `--force`；另存用 `--output`。生成器不接收远程链接、绝对素材路径或越出任务目录的引用。保持整个目录一起移动，不能只拷 HTML 而丢掉图片/TXT。

## 交付前验证

- 真正打开网页，检查图片加载、文本完整、段号/镜号对应、复制按钮与 TXT 下载；本地剪贴板被浏览器阻止时，页面应提供可选择的原文而非假报成功。
- 手机窄屏不溢出；图像等比显示，视频不自动播放；页面不需要外部字体或 CDN。
- 核对参考原文件名、绑定顺序与职责。工作台标签不是平台已绑定附件，上传到生成平台后仍需核对。
- 用户资料只在其授权范围内放入交付包；只允许本地使用的素材不上传 GitHub。分享前检查 HTML、TXT、清单和媒体中的私密内容。
- 使用用户指定输出目录；没有指定时使用任务专用目录，不把维护者电脑盘符固化到通用技能。
- “提示词已检查”“抽帧已检查”“视频已验收”分开；文字或文件计数不证明运镜、剧情或音轨已成功。

技能仓库只带规则、必要脚本和已有轻量示例，不带本次用户素材、原始视频、宣传海报或研究缓存。历史风格示例并非本版性能测试。
