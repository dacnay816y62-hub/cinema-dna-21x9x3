## 仓库 About 与 Topics

逐仓库简介和标签保存在 [github-home-settings.json](github-home-settings.json)。在仓库首页 About 的设置入口应用相应值。Topics 应设置在 GitHub 的真实标签栏，不需要把关键词列表贴回 README。

## 账号邮箱

需要隐藏未来提交的邮箱时，在 GitHub 的邮箱设置中启用隐私选项，并核对实际使用的提交工具。历史提交和已经存在的副本不会因为修改简介而自动改变。

参见 [GitHub 提交邮箱设置](https://docs.github.com/en/account-and-profile/how-tos/email-preferences/setting-your-commit-email-address)。
