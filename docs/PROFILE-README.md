# FANTASY / 梵想美学

## 让想象先被看见。

我把摄影、电影、角色与平面设计中的视觉判断，整理成可重复使用的 AI 创作 Skills。

从一个主题、一张参考或一段故事出发，让构图、人物、光色与文字都有具体的依据。

**电影与叙事 · 角色设计 · 摄影与照片转译 · 文化海报 · 编辑与品牌设计**

> Skills 提供设计方法、提示词和工作流程；实际图像由使用环境中的图像工具生成或编辑。不同项目有不同的素材来源与制作步骤，请先阅读对应仓库的说明。

## 幻想角色：底图构建 + MJ 提示词

> **幻想角色示例由作者使用 MJ + Image2 生成与完善。角色 Skill 负责人物形象设计与底图构建：人物形象设计 → 生成角色底图 + 配套 MJ 提示词 → MJ 视觉深化 → Image2 修正与完善。**

## 使用方式

1. 选择最接近当前任务的项目，先看示例和适用范围。
2. 按仓库说明安装包含 `SKILL.md` 的文件夹；调用名以文件中的 `name` 为准。
3. 提供主题或素材，再说明必须保留的内容、用途与输出要求。
4. 用具体反馈继续修改，例如「保留人物，只调整服装结构」或「减少特写，交代空间关系」。

## 创作原则

- 先明确内容与关系，再选择视觉形式。
- 参考用于理解结构、材料和方法，来源与授权分别核对。
- 系列作品需要一致性，单张作品需要清楚的主次。
- 示例展示创作方向，最终效果仍需要创作者判断。

每个项目的许可证与素材使用说明以各自仓库为准。
