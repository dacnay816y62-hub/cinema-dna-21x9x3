# FANTASY / 分镜预演台

Beta 1 · 设计与创作：FANTASY / 梵想美学

把素材、故事顺序、镜头衔接和完整提示词放在同一张工作台上。

## 先打开

下载本仓库或 [预演台 ZIP](https://github.com/dacnay816y62-hub/cinema-dna-21x9x3/releases/download/rehearsal-beta.1/fantasy-storyboard-rehearsal-beta.1.zip)，完整解压，双击本目录的 **分镜预演台.html**。无需安装 Python，也无需模型密钥。源码模板不能直接双击使用。

推荐当前版桌面 Chrome / Edge。常用快捷键兼容 Ctrl 和 macOS 的 Command；文件夹导入、剪贴板权限和本地存储受浏览器限制，无法授权时可用文件选择、正文手动复制和便携 HTML。关闭隐私模式或清除浏览器数据前先导出。Windows Chromium 已实测；本次未实际运行 macOS Safari，不作全浏览器兼容承诺。

## 一次完整操作

1. **准备素材。** 左侧导入文件夹保留母子目录；也可新建目录，再拖入 PNG / JPG / WebP。直接从外部拖到生成组的图片同时进入「所有素材 / 未分类」。文件夹是整理方式，生成组是使用方式，两者不互相替代。
2. **选择生成方式。** A1 的「组设置」可以选分镜驱动或资产驱动。分镜驱动安排画面顺序；资产驱动加入人物、场景、道具后，用一段剧情安排表演与镜头。参考上传顺序不是镜头顺序。切换模式保留原资料，不会擅自把定妆照变成分镜。
3. **编排与标注。** 用卡片手柄拖动调序；按住图片左键滑过可多选，复选框也能多选。右键选已有颜色或新建唯一组号；标记「待修改」会灰显。固定镜号不会因排序改变。组内最多两列，图与图间可设置转场，每镜可设置运镜。
4. **标注参考职责。** 同一素材可以属于多个生成组，每组独立填写人物 / 场景 / 道具等职责，以及继承、不继承的内容。文件名和素材名称应明确且不重复；三视图是同一角色的多个视角，不是多个人。
5. **查看和复制。** 点击任意素材图片打开原图；滚轮缩放、左键平移、双击适应窗口、Esc 退出。右键复制图片有成功或失败反馈。Ctrl/Cmd+C、V、Z 保留快捷操作。右栏点击 A1、B1 等，画布同步定位该组，正文同步切换。
6. **交给助手写提示词。** 在完整正文框先写剧情要求；检查人物、场景、道具、顺序及衔接，勾选人工审看后确认分镜版，再确认导出提示词任务。把导出的 JSON 交给助手，按下方交接规范写完整中文提示词。网页本身不调用生成模型，也不会假装生成完成。
7. **回填与复核。** 助手使用同一项目 JSON 和完整正文重建工作台（见下一节）。逐组核对右栏 `@素材名` 与上传顺序；改图片、职责、运镜或顺序后，受影响的助手正文会标记待更新。`@` 纯文字不等于目标平台已绑定附件，上传后仍需在平台选择同名素材。
8. **保存与分享。** 本机自动保存不等于原 HTML 被修改。「保存便携 HTML」导出带原图、当前分组和正文的独立副本；「导出资料」保存项目 JSON。分享前检查是否含私人图片与正文。删除素材只影响项目及关联，不删除电脑上的原文件；删除前有确认，当前会话可撤销。

单图上限 25 MB，项目导入上限 200 MB，分镜与参考各最多 200 条；浏览器存储还有自身配额。大项目建议拆分并定期保存便携副本。拖放文件夹、超大图和剪贴板图片可能因浏览器策略不同而需要文件选择器。

## 给助手的一句话

```text
使用 cinema-dna-21x9x3 的分镜预演台。读取我导出的项目 JSON，逐组看原图、镜号、职责、顺序、转场和起止状态，给每组写一份独立完整的中文视频提示词。A1 等为生成组，不能当成镜号；资产组不能把人物、场景、道具当作连续镜头。保持同名 @ 引用。沿用仓库的预演台构建脚本回填，不重画界面，不改变分组或原图，不调用视频模型。完成后让我逐组复核。
```

## 维护者与助手：构建、回填

仅构建需要 Python 3.9+ 标准库；Windows / macOS / Linux 命令相同，路径按本机替换。普通浏览不需要 Python。脚本不读取环境变量中的密钥、不访问网络。

```text
python scripts/build_rehearsal_html.py --title "我的新片" --output "交付/分镜预演台.html"
python scripts/build_rehearsal_html.py "项目资料.json" --output "交付/分镜预演台.html"
python scripts/build_rehearsal_html.py "项目资料.json" --prompts "逐组正文.json" --output "交付/分镜预演台_正文版.html"
```

`逐组正文.json` 是组号到完整正文的映射，例如 `{"A1":"该组实际完整正文","B1":"另一组实际完整正文"}`。不要把说明文字当作完成的提示词。脚本只做回填与依据记录，不替助手创作；它会清除旧审看确认，等待用户复核。若只修改几组，就只提供这些组，不覆盖其余组。

输出已存在时拒绝覆盖；确认可替换后加 `--force`。新构建自动分配新的浏览器保存键，防止旧缓存覆盖新稿。网页「载入方案」限同一项目的兼容 JSON；不同项目请用构建脚本另存，不用改项目 ID 强行覆盖。

源码位于 `assets/storyboard-rehearsal/`：模板、样式、运镜与转场、素材库、快捷操作、拖动反馈、提示词状态、分组导航、原图查看器。FANTASY 原始标志位于 `assets/fantasy-brand/`，未重新绘制。全部打包进 HTML，无 CDN、外部字体或隐藏模型接口。

## 边界

这是编排与交付工具，不是视频剪辑器或生图模型。预设表达导演意图，不保证生成平台逐帧照做。计划时长、模型名称不是平台能力承诺；结构检查不能代替实际读图或成片验收。空白起始页没有用户已确认的剧情、素材或提示词。原静态「分镜与提示词」工作台、稳定技能及赛车案例仍保留。
