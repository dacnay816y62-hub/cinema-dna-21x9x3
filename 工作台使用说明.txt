三、自己准备项目并生成

需要 Python 3.9 或以上版本。生成器只用标准库，无额外安装包。
在一个中文任务目录中放好：

  我的故事/
    交付清单.json
    分镜图/镜头01.png
    分镜图/镜头02.png
    段落01/完整视频提示词.txt

交付清单的字段示例见 examples/工作台示例.json；详细字段说明见 references/delivery-contract.md。
所有素材路径都相对交付清单所在目录，且必须位于该目录以内。不接受远程 URL、绝对盘符或 ../ 越界路径。
每个片段必须有唯一 id 和 prompt_file；images 可以是空数组。有真实视频文件时才填 video。
把示例替换为自己的镜号、素材文件名、参考职责和完整正文，不能只改标题。

3.2.2 起，正文默认固定为九栏：片段任务、素材绑定、场景与起始状态、分镜时间轴、摄影机与焦点、表演与物理反馈、光线与画风、声音与台词、结束状态与限制。
九栏不规定九镜。正文全部中文，英文平台标签与原文件名写在正文外的上传清单中。
默认交付填写完成的正文。空白模板在 assets/提示词模板/完整视频提示词模板.txt；另有单镜与多镜完整示例。
工作台生成前自动检查缺栏、空栏、填空残留和英文字母；遇到错误先补齐正文，不能绕过。
仅在用户明确要求整理旧稿或自定格式时，才在对应片段清单增加 "prompt_format": "自由格式"。旧清单未填该字段也按新版固定模板检查。
这是文字结构检查，不证明剧情、轴线、台词或视频运动正确。

在 Skill 文件夹中运行：
python scripts/build_prompt_html.py "我的故事/交付清单.json"

可直接验证随包示例：
python scripts/build_prompt_html.py "examples/工作台示例.json" --output "examples/工作台重建预览.html"

默认生成到交付清单同目录，文件名为“分镜与提示词.html”。已有文件不会被静默覆盖。
确认需要重建时使用：
python scripts/build_prompt_html.py "我的故事/交付清单.json" --force

另存为一个新文件使用：
python scripts/build_prompt_html.py "我的故事/交付清单.json" --output "我的故事/分镜与提示词_新版.html"

四、模板和 Logo 在哪里

scripts/build_prompt_html.py：生成器，读取清单、分镜和 TXT。
scripts/check_prompt_template.py：正文检查器，与生成器放在同一目录，不可遗漏。
assets/提示词模板/完整视频提示词模板.txt：九栏编写模板，使用前填完并删除填空说明。
references/中文固定模板规范.md：固定格式、来源依据与完成门槛。
examples/中文提示词示例/檐下递灯.txt：填好的单镜正文。
examples/工作台示例/完整视频提示词.txt：填好的多镜正文。
assets/prompt-workspace/template.html：维护 HTML、样式和复制行为的模板源码。
assets/fantasy-brand/fantasy-logo.png：品牌所有者提供的原始 Logo，不是字体重写或 AI 重绘。
assets/fantasy-brand/brand-spec.md：品牌资产与显示规则。
examples/分镜与提示词.html：已生成的可打开示例；不要将模板源码误当最终交付页。

模板中的 TITLE、NAV、CONTENT、LOGO_DATA 注释标记由脚本填入，不要删除。
脚本把 Logo 原图内嵌到生成的 HTML；不会引用维护者电脑上的路径。
请保留 scripts 与 assets 的相对位置，不要只拷贝一个 Python 文件后运行。

五、实际使用

1. 先检查参考用途：首帧、尾态、人物、空间和画风不是同一件事。
2. 按正文约定顺序上传独立分镜图。三联/九宫格只是总览时，不要直接当单镜首帧。
3. 点击“复制完整提示词”，到所选视频平台粘贴；再核对真实附件绑定、模型、时长、画幅和音频设置。
4. 如果浏览器拦截复制，页面会选中正文并提示手动复制；也可以下载 TXT。
5. 修改 TXT 或清单后需要重新运行脚本。网页里的正文是生成当时的快照，不会实时同步外部 TXT。
6. 显示、复制、下载采用同一份网页正文快照；下载在浏览器内生成文本文件，支持直接打开本地网页，不需要启动服务器。

六、分享与隐私

Logo 已内嵌，但分镜、TXT 和视频仍是相对路径引用，因此分享时要发送完整任务文件夹。
没有视频时不会显示假播放器。离线页不调用模型，不自动生成、付费、上传或提交任何内容。
发布前自行确认图片、提示词和视频的公开权限；不要把客户素材、密钥或私人路径提交到公共仓库。
