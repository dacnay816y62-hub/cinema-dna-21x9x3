# 完整中文视频提示词

每个独立片段按以下顺序填写全部九栏。标题、正文和运镜表达使用中文；用户指定的模型名、原始文件名、品牌文字及 `@asset` 引用保持原样。用户明确另定格式时遵从，同时保留必要信息。

| 栏目 | 必须说明 |
| --- | --- |
| 片段任务 | 本段内容、时长、画幅、覆盖镜号、连续镜头或剪辑方式 |
| 素材绑定 | 每份真实素材的用途、保留内容和不继承内容；无素材则说明文字生成 |
| 场景与起始状态 | 世界位置、人物姿态、道具归属、开始时的情绪与动作 |
| 分镜时间轴 | 从零开始的连续时段、事件顺序、切点；覆盖本段总时长 |
| 摄影机与焦点 | 起始机位、路径、朝向、景别变化、移焦对象和最终位置 |
| 表演与物理反馈 | 人物目的、可见微动作、接触先后、重量与惯性，不堆无关细节 |
| 光线与画风 | 光源位置、色彩、媒介与纹理；继承用户选定风格 |
| 声音与台词 | 有无音乐、环境声、说话人、内容和时机；不可擅自添加对白 |
| 结束状态与限制 | 最后姿态、实体归属、衔接条件、重要禁止变化和未知项 |

不保留填空符，不用公共前缀加镜头短句要求用户拼接。每段独立写全世界、人物和状态，只重复该段所需内容。九栏不等于九镜，不预设三十秒或三段。

素材清单保留原始文件名。用户要求 `@asset` 时逐条写如“@asset1：人物身份，继承五官和服装，不继承棚拍背景”；先核实实际附件与标签对应，不能以示例编号冒充真实绑定。素材顺序变化后同步正文。

人物定妆图、空间母版、首帧、尾帧和中间动作参考不能互换职责。已有视频延长必须有源视频。运镜参考与文字路径冲突时按用户主参考处理，不叠加另一套动作。

## 已填写示例：檐下递灯

以下为八秒写法示例，未生成对应视频；不作为所有任务的固定剧情或时长。

### 片段任务
生成八秒横向连续镜头：雨夜屋檐下，穿灰外套的甲将一盏提灯交给穿蓝外套的乙。全段不切镜。

### 素材绑定
本例没有参考附件，按文字建立两位原创成年人物和同一处屋檐，不宣称已有绑定素材。

### 场景与起始状态
两人站在同一屋檐下相距约一臂，甲在画面左侧用右手提着唯一一盏灯，乙在右侧，双手空着。灯光照亮两人的手，远处雨幕可见。

### 分镜时间轴
零至两秒，甲看向乙并略微抬灯；两至五秒，乙伸出左手握住灯柄，甲确认乙握稳后松手；五至八秒，乙独自持灯收回身前，甲的右手自然垂下。

### 摄影机与焦点
摄影机从两人正前方的中景缓慢向前移动半步，始终留在同一动作轴侧；先让两张脸可读，交接时将注意力落在两只手与灯柄上，最后保持两人和提灯同框，不绕到身后。

### 表演与物理反馈
甲先抬灯再等待，乙握稳后甲才松手。灯身因交接产生轻微摆动并逐渐稳定；乙承接重量时手腕自然下沉，没有瞬移或第二盏灯。

### 光线与画风
真实电影摄影质感，雨幕呈冷灰蓝色，提灯提供局部暖光。面部曝光可读，皮肤自然，光源位置不随相机移动。

### 声音与台词
保留雨声、轻微衣料摩擦和灯柄接触声，无对白，无配乐。

### 结束状态与限制
尾态为乙左手独持唯一提灯，甲双手空着，两人仍在屋檐下。人物外貌和服装不变，不新增旁人，不出现灯具复制、穿模或手指异常。

## 执行边界

保留“可用时优先使用 Seedance 2.5”的偏好，但具体版本和入口由实际环境决定。核对所选任务支持的参考、首尾帧、时长、比例、分辨率和声音，未知项标未验证。自然语言的秒点和光学描述表达导演意图，不保证逐帧精准执行。

文件或正文结构检查仅能确认九栏齐全、时段连贯、引用对应；不能代替实际视频播放和关键交互检查。
