# 影视工业级宽银幕分镜

电影感来自观看位置、人物关系、可见动作、真实光源和剪辑节奏。先满足用户剧情和资产事实，再处理连续性、镜头、美术。用户指定的媒介、画幅、数量、时长、模型偏好和交付格式优先于默认值。

## 交付分支

| 用户意图 | 应交付的结果 |
| --- | --- |
| 一张电影静帧 | 一张独立画面，不附加多镜任务 |
| 三联或未指定数量的电影分镜测试 | 三张独立镜头，再纵向拼接 |
| 九镜、九张讲故事 | 九张独立镜头、三张纵向三联及一张三乘三总览 |
| 视频提示词或运镜方案 | 按实际剧情分段的完整中文正文，不自动生成视频 |
| 图像加提示词 | 独立图、镜号、参考用途、对应完整正文；文件交付附文本和可复制的浏览工作台 |
| 实际视频 | 使用可用的视频创作能力执行用户要求，按真实成片验收 |

静帧默认横向约 2.39:1；精确 21:9 等于 7:3，两者不得混称。用户指定精确尺寸时按其要求检查输出；不靠拉伸纠正比例。静帧数、剪辑镜头数和生成片段数分别规划，九图不等于九段视频，三张长镜头关键状态不等于三个切镜。

图像生成能力接收本镜完整描述、画幅和允许使用的参考，返回一张可独立检查的镜头。图像编辑能力用于定向修复，需锁住其他已通过部分。拼版能力仅组合已通过的源图，不重新发明内容。视频创作能力接收完整片段描述与职责明确的素材，返回实际可播放片段。具体执行方式由环境选择；保留用户明确指定的模型与服务偏好，不静默替换。

## 剧情、参考与状态

多镜故事先读 [连续性与空间](references/连续性与空间.md)。提供画风参考、要求保留人物或修复漂移时，也按该文档建立参考职责。

1. 完整故事默认忠实分镜，保持事件、顺序、人物关系和结局；开放命题才补充原创情节。三镜扩九镜优先细分接近、动作、反应、结果，不凭空加反转。
2. 给每份素材注明用途：灵感、画风、身份、场景、产品、首帧、尾帧或当前状态。多用途时逐项说明继承范围。
3. 保留画风就锁住媒介、线条、色块、明暗和局部纹理；电影感不授权把手绘改真人。“参考不作为成片一帧”不等于“禁止作为生成参考”。明确禁止传入的素材不可传入。
4. 记录镜号、来源事实、镜前状态、主要事件、镜后状态、机位轴线、必须可见的证据和依赖镜号。固定身份与可转移道具分开管理。
5. 区分画面可见事实、有依据的推测、未知空间。没有背面依据时避免擅自反拍或全环绕；需要扩展空间时说明假设。

## 镜头设计与生成

每镜先确定观众新看到什么，再定机位、景别和遮挡。普通过渡、重复构图、停顿和无冲突的观察都可以成立，不套固定戏剧节拍。不为镜头多样性违背“不要特写”等限制。

逐镜提示词包括：单帧与媒介画幅；当前身份及实体状态；可见动作阶段；摄影机实体位置、拍向和透视；前中后景；光源、综合色与材质；相关排除项。原画风优先，只有无媒介要求且无画风参考时默认真人实景电影质感。

每个镜头独立生成，不让图片生成能力一次画三联或九宫格。关键状态变化镜先检查，再生成依赖镜。必要时使用计划内一镜校准，不额外增加整套定妆图。不要只引用上一镜导致画风漂移，也不要让初态参考覆盖后续交接、损坏或服装变化。

拼版保持源图比例，默认黑色小间隔、无额外文字；用户指定标注时再加。源图必须单独保留，方便替换。

## 视频提示词

涉及视频或运镜时读取 [完整中文视频提示词](references/完整中文视频提示词.md)。默认交付九栏完整中文正文，每段可独立复制，不交空白模板，不写“同上”。九栏是本技能的交付格式，不是即梦官方强制语法。

可用时优先使用 Seedance 2.5；用户明确指定其他模型时按其选择执行。此偏好不代表当前账户一定可用。实际生成前核对当前入口支持的参考、首尾帧、时长、画幅和声音；不编造支持范围。用户要求用 `@asset` 逐条标注时，保留该格式并写明素材用途；未上传时仅称上传计划，不称已绑定。

摄影机位移、摇摄、变焦、移焦分别描述；复合运动说明先后和路径。片段选择连续镜头、多镜剪辑、逐镜独立或已有视频延长，不机械三等分。时间与动作量相称，每段从零开始，覆盖完整时长。

## 返修与交付检查

先查剧情事实、角色可辨、实体数量和归属、媒介画风、空间关系、动作可达性，再查构图、色彩、节奏和材质。每项记通过、失败或无法判断；看不清不能算通过。交接镜必须同时看到接手和原持有人松手或其结果依据。

记录每镜提示词、修订、参考职责、输出和实际观察。出错时区分指令冲突、参考过时、未遵从和能力不足，只修有关镜头并复核下游；同镜默认最多定向补跑两次，用户另定预算时遵从。不得用规避限制的措辞重试。

实际视频检查首、中、尾及动作关键时刻，区分主体运动与相机运动。只完成提示词时明确视频未生成，不用静帧或结构检查宣称运动成功。

图文文件任务读取 [文件交付](references/文件交付.md)。缺少媒体或文件生成能力时，交付已完成的完整中文方案并说明未生成项；不把文本包装成成片。
